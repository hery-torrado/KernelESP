## Upload Command

```sh
tools/upload.sh
tools/upload.sh /dev/cu.usbserial-02094OMK
```

After a successful serial upload, `tools/upload.sh` automatically sends
`wifi sdkreset --yes` to clear stale ESP8266 SDK Wi-Fi state before the board
reconnects.

`tools/upload.sh` expects a local Python virtual environment at `.venv/` with `pyserial` installed, or a custom `PYTHON` environment variable. Create it with:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install pyserial
```

Known direct esptool form:

```sh
python3 \
  "$HOME/Library/Arduino15/packages/esp8266/hardware/esp8266/3.1.2/tools/esptool/esptool.py" \
  --chip esp8266 \
  --port /dev/tty.usbserial-02094OMK \
  --baud 115200 \
  --before default_reset \
  --after hard_reset \
  --no-stub write_flash \
  --flash_mode dout \
  --flash_freq 40m \
  --flash_size 4MB \
    0x0 build/esp8266.esp8266.generic/KernelESP.ino.bin
```

If upload fails with `Device not configured`, wait a few seconds and retry.

## Last Verified Runtime State

KernelESP 0.10.0 includes the Professional Live UI panel, read-only diagnostic
export, board profiles, release tooling, HTTP smoke tests, web auth lockout,
config schema migration defaults, mail alerts through a LAN SMTP relay, and the
`board`, `diag` and `mail` commands. It also includes lightweight pipes for
serial, the web command runner and `/api/cmd`:

```text
health | grep wifi
dmesg | tail -n 5
health | wc -l
health | tee /home/health.txt
```

The UI is served from LittleFS static files
(`/www/index.html`, split `app*.js`, `i18n*.js`, `/www/style.css` and
`/www/style2.css`) so large interface changes do not increase IRAM.

The web Help section has English, Spanish and Portuguese topic files, including
a dedicated `email` topic for SMTP alert workflows and a `mail` topic for the
command reference. Repository manuals under `docs/` remain English.

Runtime address should be read from serial with `wifi status` or `web status`.
When fallback AP is active, the ESP uses `192.168.4.1`.

Previously tested runtime envelope:

```text
Version:  KernelESP 0.10.0 after upload check
Heap:     about 30-33 KB free during API/web use
LittleFS: about 1.00 MB free after Live UI and translated help assets
```

Current stabilization policy:

- Prefer bug fixes, stability, security, documentation, ergonomics and memory
  reduction.
- Avoid new firmware features unless they replace risk or simplify operation.
- Keep larger UI/help work in LittleFS assets.
- Run `tools/verify.sh`, `tools/smoke-http.sh` and a short
  `tools/stability-http.sh` pass after meaningful changes.
