WI-FI
=====

Estado y escaneo:

  wifi status
  wifi net
  wifi scan
  ip

Guardar y conectar:

  wifi save "SSID" "password"
  wifi reconnect
  wifi wait 30

DHCP o IP fija:

  wifi dhcp on
  wifi static IP GATEWAY MASK DNS1 DNS2

Recuperacion:

  wifi recover
  wifi sdkreset --yes
  wifi diag

Tras una subida por serie, tools/upload.sh ya ejecuta wifi sdkreset.

Errores habituales:

  201 no_ap_found   el SSID no es visible para el ESP8266
  202 auth_fail     revisar password y seguridad del AP
  beacon_timeout    senal, interferencia o carga del AP

El ESP8266 solo usa Wi-Fi 2.4 GHz.
