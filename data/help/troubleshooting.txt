TROUBLESHOOTING
===============

Start with a read-only snapshot:

  health
  free
  df
  dmesg
  wifi status
  jobs

Wi-Fi does not connect:

  wifi scan
  wifi diag
  wifi recover
  wifi sdkreset --yes

Remember: ESP8266 only supports 2.4 GHz.

Web UI is unreachable:

  wifi status
  web status
  service web restart
  ap status

Time is wrong:

  ntp kick
  ntp status
  date

If you need to wait manually, use:

  ntp sync

Cron did not run:

  date
  crontab -l
  jobs
  dmesg

Sensor not found:

  i2c scan
  sensor begin 0x76 D2 D1
  sensor begin 0x77 D2 D1

Relay works backwards:

  relay rm light
  relay add light D1 active_high
  relay boot light off

Mail does not send:

  mail status
  ping smtp.lan 25
  wifi status
  dmesg

If automation gets unsafe:

  disarm
  safe next
  reboot

After safe boot:

  cron clear
  rule clear
  timer clear
  safe off
