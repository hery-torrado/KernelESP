ALERTAS POR EMAIL
=================

KernelESP envia SMTP simples através de um relay interno de confiança:

  KernelESP -> Postfix interno -> smart host -> caixa de correio

O firmware evita TLS e autenticação SMTP para poupar RAM e flash. O relay SMTP
deve estar numa LAN confiável e aceitar email apenas de dispositivos conhecidos.

Configuração inicial:

  mail config smtp.lan 25 kernelesp@example.lan admin@example.lan
  mail status
  mail test "Manual test from KernelESP"

Relatório manual de saúde:

  mail health "KernelESP daily health"

Relatório diário às 08:00:

  ntp kick
  cron add daily 08:00 mail health "KernelESP daily health"
  crontab -l

Alerta de temperatura com ventoinha:

  relay add fan D5 active_low
  relay boot fan off
  sensor begin
  rule cooldown 300000
  write /home/heat-on.sh relay on fan
  append /home/heat-on.sh mail send default "KernelESP heat alert" "Temperature is above 40 C. Fan is on."
  write /home/heat-off.sh relay off fan
  append /home/heat-off.sh mail send default "KernelESP temperature normal" "Temperature is below 38 C. Fan is off."
  rule add temp range 38 40 sh /home/heat-on.sh
  rule off 1 sh /home/heat-off.sh

Alerta de fluxo elétrico a partir de entrada digital:

  input add power D2 pullup 50
  write /home/power-lost.sh mail send default "KernelESP power alert" "Power flow has stopped."
  input on power low sh /home/power-lost.sh

Evita ciclos de email:

  rule cooldown 300000
  rule list
  dmesg

A placa deve continuar alimentada para enviar alertas. Usa UPS ou bateria se o
alerta depender de perda de energia elétrica.

Diagnóstico:

  mail status
  ping smtp.lan 25
  wifi status
  dmesg
