MAPA DE COMANDOS
================

A maioria dos comandos funciona por serial, na caixa Command da web, em
/api/cmd, scripts, cron, regras e entradas. Usa `help <comando>` para uma
sintaxe curta, por exemplo `help who` ou `help wifi`.

Shell basico:

  help [cmd]       lista comandos ou explica um
  clear            limpa a vista do terminal com linhas em branco
  echo texto       imprime texto
  history          mostra comandos recentes
  alias            lista ou cria atalhos
  unalias nome     remove um atalho
  env, printenv    lista variaveis volateis da shell
  set nome valor   cria ou altera uma variavel volatil
  unset nome       remove uma variavel volatil
  true, false      comandos simples para scripts e testes
  test -f rota     verifica ficheiros, diretorios ou valores

Utilizador e processos:

  whoami           utilizador atual, sempre root
  id               identidade root fixa usada pela shell
  groups           grupos da shell
  who              sessao de shell ativa, por exemplo root ttyS0
  w                uptime, heap e sessao ativa
  ps, top          pseudoprocessos: shell, wifi, LittleFS, timers, regras, cron
  jobs             timers, regras e cron
  pgrep texto      procura pseudoprocessos que contem texto
  pidof texto      imprime ids de pseudoprocessos correspondentes
  kill pid         remove um timer, regra ou cron
  sync             compatibilidade; LittleFS escreve imediatamente

Sistema:

  version          versao do firmware
  uname            firmware, placa e sistema de ficheiros
  uptime, uptime -p
  health           resumo completo do sistema
  diag             pacote de diagnostico apenas de leitura
  board            perfil da placa e pinos seguros
  free, heap, mem  heap, fragmentacao e maior bloco livre
  df, df -h        espaco de LittleFS
  du, du -h rota   uso de ficheiro ou diretorio
  dmesg            log de eventos em RAM
  log              ferramentas de log em flash/RAM
  logger texto     adiciona uma linha ao log
  journalctl       mostra eventos ou a cauda do log em flash
  resetreason      motivo do ultimo reinicio
  chip             chip id, flash id e versao do SDK
  flash            tamanho e velocidade da flash
  sysinfo          resumo de chip, flash, memoria e reinicio
  reboot           reinicia a placa
  safe             confirmacao de seguranca por etapas
  dryrun           simula escritas GPIO/relay
  arm, disarm      ativa ou pausa automacoes
  armed            mostra o estado de automacao

Email:

  mail status
  mail config postfix.lan 25 kernelesp@lan admin@example.com
  mail test "Manual test from KernelESP"
  mail health "KernelESP daily health"
  mail send default "KernelESP alert" "Temperature is high"

Tempo:

  date             hora local da placa
  date -u          hora UTC
  ntp status
  ntp kick         atualizacao nao bloqueante para scripts/cron
  ntp sync         sincronizacao manual bloqueante para testes
  ntp auto on|off
  ntp fallback on|off
  ntp server pool.ntp.org time.nist.gov
  ntp tz -4

Nota NTP: os campos de servidor contem nomes de host. ntp tz e apenas o
desvio UTC numerico em horas, por exemplo 0, 1, 2, -5 ou 5.5. Nao coloques um
servidor como hora.roa.es em ntp tz.

Ficheiros:

  pwd              diretorio atual
  cd dir           muda de diretorio
  ls rota          lista ficheiros
  cat ficheiro     imprime um ficheiro
  head, tail       primeiras ou ultimas linhas
  grep texto file  linhas correspondentes
  find dir texto   lista ficheiros, opcionalmente filtrando texto
  wc ficheiro      linhas, palavras e bytes
  stat rota        metadados de ficheiro, diretorio ou pseudo-ficheiro
  basename rota    ultimo componente da rota
  dirname rota     diretorio pai
  touch ficheiro   cria um ficheiro
  write file texto substitui o ficheiro por texto
  append file txt  acrescenta texto
  rm ficheiro
  mkdir dir
  rmdir dir
  cp src dst
  cp -r dir dst
  mv src dst
  mount            pseudosistemas de ficheiros
  which cmd        indica se o comando e integrado
  fsformat --yes   apaga LittleFS

  i2c scan

Reles e automacao:

  relay add light D1 active_low
  relay on|off|toggle light
  relay pulse light 500
  relay boot light off
  relay status
  cron add daily 08:00 relay on pump
  cron add dow thu 08:20 relay off pump
  cron add date 05-01 11:00 sh /home/may1.sh
  crontab -l
  timer once 300000 relay off light
  timer every 60000 health
  rule add temp range 38 40 relay fan
  input add button D2 pullup
  scene add night relay off light; relay on security
  scene run night
  schedule pump 08:00 08:05
  climate hum extractor 60 70

Expressoes e scripts:

  if (temp >= 40 && time < 10:00) relay on fan
  if (wifi == connected) { logger online } else { logger offline }
  when pin D2 pulse if (armed == on) mail health "Door pulse"
  let irrigation.enabled = 1
  define HOT 40
  function water_zone1 { relay on valve1; timer once 600000 relay off valve1 }
  call water_zone1
  repeat 5 relay status
  watch 10000 health
  sleep 500
  sh /home/test.sh
  sh -n /home/test.sh
  source /home/test.sh
  run /home/test.sh
  boot show|set|run
  onboot list|add|rm|clear
  pkg list|add|run|show|rm
