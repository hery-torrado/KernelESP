SAFETY
======

KernelESP switches GPIO pins. It must never power mains loads directly.

For 110/230 V, pumps, heaters, motors, locks or valves:

  - use certified relay/contactor modules
  - isolate low voltage and mains wiring
  - use fuses and proper enclosures
  - test with the real load disconnected first
  - keep manual override/disconnect access

Choose safe pins first:

  D1 D2 D5 D6 D7

Avoid boot-sensitive pins unless you understand the board:

  D0 D3 D4 D8 RX TX

Set safe relay boot state before wiring the load:

  relay boot pump off
  relay boot heater off
  relay boot fan off

Pause all automation:

  disarm

Resume:

  arm

Use dry-run before testing risky workflows:

  dryrun on
  relay on pump
  relay off pump
  dryrun off

Emergency cleanup:

  disarm
  safe next
  reboot
  cron clear
  rule clear
  timer clear
