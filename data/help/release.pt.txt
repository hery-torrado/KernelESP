RELEASE
=======

Verificar localmente:

  tools/verify.sh

Criar pacote:

  tools/release.sh

Enviar firmware:

  tools/upload.sh /dev/cu.usbserial-02094OMK

Enviar web/help:

  tools/upload-assets.sh http://<esp-ip> admin

Testes:

  tools/smoke-http.sh http://<esp-ip> admin
  COUNT=120 DELAY=1 tools/stability-http.sh http://<esp-ip> admin

As notas de release devem focar correcoes, estabilidade e limites conhecidos.
