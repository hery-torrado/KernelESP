INPUTS
======

Inputs watch digital pins and run commands on high, low or change events.

Create an input:

  input add button D2 pullup 50
  input list

Run a command when the input goes low:

  input on button low relay toggle light

Run a command only when extra conditions are true:

  when input button pulse if (temp > 40 && time < 10:00) relay on fan

Create a pin watcher and conditional action in one command:

  when pin D2 pulse if (temp >= 40 && time < 10:00) relay on fan

Use persistent variables, constants and functions:

  let irrigation.enabled = 1
  define MORNING_END 10:00
  when pin D2 pulse if (irrigation.enabled == 1 && time < MORNING_END) { relay on trees; timer once 900000 relay off trees; logger trees_started }

Use a block when one event should run several commands:

  when input button low if (wifi == connected) { logger button_low; mail health "Button pressed" } else { logger button_low_no_wifi }

Run a script:

  write /home/power-lost.sh mail send default "KernelESP power alert" "Power flow has stopped."
  input add power D2 pullup 50
  input on power low sh /home/power-lost.sh

Read and remove:

  input read button
  input rm button
  input clear

Use pullup for buttons wired to GND. If the board loses power at the same time
as the monitored circuit, it needs a UPS or battery to send the alert.
