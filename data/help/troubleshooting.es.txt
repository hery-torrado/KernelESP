PROBLEMAS
=========

Empieza con una foto de solo lectura:

  health
  free
  df
  dmesg
  wifi status
  jobs

Wi-Fi no conecta:

  wifi scan
  wifi diag
  wifi recover
  wifi sdkreset --yes

Recuerda: ESP8266 solo soporta 2.4 GHz.

La web no responde:

  wifi status
  web status
  service web restart
  ap status

La hora está mal:

  ntp kick
  ntp status
  date

Si necesitas esperar manualmente:

  ntp sync

Cron no ha ejecutado:

  date
  crontab -l
  jobs
  dmesg

Sensor no encontrado:

  i2c scan
  sensor begin 0x76 D2 D1
  sensor begin 0x77 D2 D1

El relé funciona al revés:

  relay rm light
  relay add light D1 active_high
  relay boot light off

El email no sale:

  mail status
  ping smtp.lan 25
  wifi status
  dmesg

Si una automatización se vuelve insegura:

  disarm
  safe next
  reboot

Después del arranque seguro:

  cron clear
  rule clear
  timer clear
  safe off
