HARDWARE
========

O ESP8266 usa GPIOs de baixa potencia. Servem para comandar modulos de rele ou
sensores, nao para alimentar cargas diretamente.

Pinos comodos em NodeMCU/Wemos:

  D1, D2, D5, D6, D7

Pinos delicados:

  D0, D3, D4, D8, RX, TX

Alguns influenciam o arranque ou a consola serie. Em caso de duvida, usa D1
para um rele simples e D2/D1 para I2C.

Rele:

  GPIO -> IN do modulo
  GND  -> GND
  VCC  -> alimentacao do modulo

O lado COM/NO/NC comuta a carga externa. Para rede eletrica usa caixa, fusivel,
isolamento e modulos certificados.

Sensor BMP280/BME280:

  VCC -> 3.3 V
  GND -> GND
  SDA -> D2 / GPIO4
  SCL -> D1 / GPIO5

Teste seguro:

  relay add test D1 active_low
  relay pulse test 300
  relay rm test
