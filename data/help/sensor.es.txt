SENSORES
========

KernelESP soporta BMP280 y BME280 por I2C.

  BMP280: temperatura y presion
  BME280: temperatura, presion y humedad

Cableado tipico:

  VCC -> 3.3 V
  GND -> GND
  SDA -> D2 / GPIO4
  SCL -> D1 / GPIO5

Escanear:

  sensor scan
  i2c scan

Iniciar:

  sensor begin
  sensor begin 0x76 D2 D1
  sensor begin 0x77 D2 D1

Leer y guardar:

  sensor read
  sensor status
  sensor save 0x76 D2 D1
  sensor autostart on

Si no aparece, revisa alimentacion 3.3 V, GND, orden SDA/SCL y direccion 0x76
o 0x77.
