PROBLEMAS
=========

Começa com uma foto só de leitura:

  health
  free
  df
  dmesg
  wifi status
  jobs

Wi-Fi não liga:

  wifi scan
  wifi diag
  wifi recover
  wifi sdkreset --yes

Lembra: ESP8266 só suporta 2.4 GHz.

A web não responde:

  wifi status
  web status
  service web restart
  ap status

A hora está errada:

  ntp kick
  ntp status
  date

Se precisares de esperar manualmente:

  ntp sync

Cron não executou:

  date
  crontab -l
  jobs
  dmesg

Sensor não encontrado:

  i2c scan
  sensor begin 0x76 D2 D1
  sensor begin 0x77 D2 D1

O relé funciona ao contrário:

  relay rm light
  relay add light D1 active_high
  relay boot light off

O email não sai:

  mail status
  ping smtp.lan 25
  wifi status
  dmesg

Se uma automação ficar insegura:

  disarm
  safe next
  reboot

Depois do arranque seguro:

  cron clear
  rule clear
  timer clear
  safe off
