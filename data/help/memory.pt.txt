MEMORIA
=======

Verificar:

  free
  health
  df

Valores:

  heap       RAM livre
  frag       fragmentacao
  max block  maior bloco livre continuo
  fs_free    espaco LittleFS livre

Bons sinais:

  - heap acima de 20 KB
  - fragmentacao controlada
  - max block suficiente para pedidos web
  - LittleFS com espaco livre

O log persistente esta desligado por defeito para proteger a flash.

Usa primeiro:

  dmesg

Se a web ficar instavel:

  free
  dmesg
  service web restart
