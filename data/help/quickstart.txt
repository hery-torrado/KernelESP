QUICK START
===========

1. Check the board:

  version
  health
  free
  df

2. Check network and time:

  wifi status
  ifconfig
  ntp kick
  date

Use ntp kick in scripts, boot and cron because it returns immediately. Use
ntp sync only from serial/web when you want to wait for a manual result.

3. Add a relay safely:

  relay add light D1 active_low
  relay boot light off
  relay status
  relay pulse light 500

If the relay works backwards, recreate it with active_high.

4. Add a daily schedule:

  cron add daily 08:10 relay on light
  cron add daily 08:20 relay off light
  cron list

5. Add a sensor rule:

  sensor scan
  sensor begin
  relay add fan D5 active_low
  rule add temp range 38 40 relay fan
  rule list

6. Optional mail alerts:

  mail config postfix.lan 25 kernelesp@lan admin@example.com
  mail test "Manual test from KernelESP"

Before leaving the board unattended:

  relay status
  rule list
  crontab -l
  input list
  jobs
  health
  backup

If anything looks unsafe:

  disarm
  safe next
  reboot
