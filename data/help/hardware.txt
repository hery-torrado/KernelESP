HARDWARE
========

The ESP8266 is a small Wi-Fi microcontroller. Its GPIO pins provide low-power
digital signals. They can command relay modules and sensors; they must not
power loads directly.

Common wiring:

  ESP8266 -> relay module -> external load
  ESP8266 -> I2C sensor   -> temperature/humidity/pressure

Recommended GPIOs on NodeMCU/Wemos style boards:

  D1, D2, D5, D6, D7

Be careful with:

  D0, D3, D4, D8, RX, TX

Some pins affect boot mode or serial communication. If in doubt, start with D1
for a simple relay and D2/D1 for I2C.

Show pin guidance:

  pins
  board pins

Relay modules:

  ESP8266 GPIO -> relay IN
  GND          -> relay GND
  VCC          -> relay module supply

Load side:

  COM and NO/NC open or close the external circuit.

NO means normally open. NC means normally closed.

Power:

Weak supplies cause resets, disappearing web UI, relay clicks during boot and
Wi-Fi dropouts. Use a stable supply and enough current for relay modules.

Typical BMP280/BME280 I2C wiring:

  VCC -> 3.3 V
  GND -> GND
  SDA -> D2 / GPIO4
  SCL -> D1 / GPIO5

Safe initial test:

  relay add test D1 active_low
  relay pulse test 300
  relay off test
  relay rm test
