ENTRADAS
========

As entradas vigiam pinos digitais e executam comandos em high, low ou change.

Criar:

  input add button D2 pullup 50
  input list

Executar comando ao baixar:

  input on button low relay toggle light

Exemplo de falha de energia:

  input add power D2 pullup 50
  write /home/power-lost.sh mail send default "KernelESP power alert" "Power flow has stopped."
  input on power low sh /home/power-lost.sh

Ler e apagar:

  input read button
  input rm button
  input clear

Se a placa tambem perder alimentacao, precisa de UPS ou bateria.
