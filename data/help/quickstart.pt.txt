PRIMEIROS PASSOS
================

Verifica a placa:

  version
  health
  free
  df

Wi-Fi:

  wifi status
  wifi scan
  ip

Hora:

  ntp sync
  date

Rele basico:

  relay add light D1 active_low
  relay boot light off
  relay pulse light 500

Sensor:

  sensor scan
  sensor begin
  sensor read

Automacao diaria:

  cron add daily 08:10 relay on light
  cron add daily 08:20 relay off light

Regra de temperatura:

  relay add fan D5 active_low
  sensor begin
  rule add temp range 38 40 relay fan

Email:

  mail config postfix.lan 25 kernelesp@lan admin@example.com
  mail test "Manual test from KernelESP"

Antes de deixar sem vigilancia:

  relay status
  rule list
  crontab -l
  input list
  health
  backup
