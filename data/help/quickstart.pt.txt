PRIMEIROS PASSOS
================

1. Verifica a placa:

  version
  health
  free
  df

2. Verifica rede e hora:

  wifi status
  ifconfig
  ntp kick
  date

Usa ntp kick em scripts, arranque e cron porque retorna imediatamente. Usa
ntp sync só pela consola série/web quando quiseres esperar por resultado manual.

3. Adiciona um relé com segurança:

  relay add light D1 active_low
  relay boot light off
  relay status
  relay pulse light 500

Se o relé funcionar ao contrário, recria-o com active_high.

4. Adiciona um horário diário:

  cron add daily 08:10 relay on light
  cron add daily 08:20 relay off light
  cron list

5. Adiciona uma regra de sensor:

  sensor scan
  sensor begin
  relay add fan D5 active_low
  rule add temp range 38 40 relay fan
  rule list

6. Alertas por email opcionais:

  mail config postfix.lan 25 kernelesp@lan admin@example.com
  mail test "Manual test from KernelESP"

Antes de deixar a placa sozinha:

  relay status
  rule list
  crontab -l
  input list
  jobs
  health
  backup

Se algo parecer inseguro:

  disarm
  safe next
  reboot
