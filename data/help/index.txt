KERNELESP HELP
==============

KernelESP turns an ESP8266 into a tiny UNIX-like controller: serial shell, web
UI, LittleFS files, Wi-Fi recovery, relays, sensors, cron, rules, inputs,
scripts, backups, diagnostics and mail alerts.

Recommended path:

  1. Check the board and network: health, wifi status, date.
  2. Queue time sync with ntp kick. Use ntp sync only when testing manually.
  3. Configure relays with a safe boot state before connecting real loads.
  4. Test sensors and inputs manually.
  5. Add one automation at a time, then inspect jobs and dmesg.
  6. Configure mail only through a trusted LAN SMTP relay.
  7. Create a backup/profile after the system behaves correctly.

Useful first commands:

  help quickstart
  help commands
  health
  wifi status
  ntp kick
  date
  relay status
  sensor read
  jobs
  backup

Key topics:

  quickstart       Setup path from empty board to first automation.
  commands         Compact command map.
  hardware         Pins, boot-sensitive GPIO and wiring notes.
  relay            Relay setup, active_low/active_high and safe boot.
  cron             Daily, weekday and date schedules.
  email            SMTP relay setup and alert recipes.
  safety           What to check before switching real loads.
  troubleshooting  If something is not working, start there.

Use:

  help <topic>
